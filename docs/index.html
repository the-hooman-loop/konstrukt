The Hooman Loop Design System

Konstrukt

The single source of truth for design tokens across all The Hooman Loop surfaces — web apps, marketing sites, and native iOS. Authored once as JSON, generated into CSS, Swift, and a machine-readable manifest.

Style Bauhaus / Swiss International Palettes 5 Modes Light + Dark

Principles

FlatNo drop shadows. Elevation is communicated with borders and weight, never blur. --shadow: none.
SquareCorners are sharp by default. --radius: 0px.
TypographicSpace Grotesk for display, Inter for body, SF Mono for code. Hierarchy carries the layout.
Restrained colorAn off-white canvas, near-black ink, one teal accent. Status and segment colors are reserved for meaning.
GridA strict 4px spacing scale, --sp-1 through --sp-16.

Two axes

Every theme is the intersection of a palette and a mode, set as attributes on <html>. Use the controls in the header to preview any combination across these docs.

<html data-palette="hl" data-mode="dark">

How it is built

Tokens live as W3C DTCG JSON in apps/konstrukt/tokens/. A Style Dictionary build emits one CSS selector block per palette and mode, a Swift package, and the JSON manifest. A parity check confirms the generated CSS matches the portal's canonical tokens value-for-value.

cd apps/konstrukt
npm run build     # tokens -> dist/{css,swift,tokens.json}
npm run check     # parity gate vs canonical CSS
