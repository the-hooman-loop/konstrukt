Typography

Space Grotesk sets display and headings; Inter carries body copy; SF Mono is reserved for code and values.

Families

RoleTokenFamily
Display--font-displaySpace Grotesk
Body--font-sansInter
Mono--font-monoSF Mono

Roles

Each role is a --type-<role> font shorthand plus -tracking and -transform. Rendered live from the manifest; Swift gets the same roles as KonstruktTextStyle.

h1 {
  font: var(--type-display);
  letter-spacing: var(--type-display-tracking);
  text-transform: var(--type-display-transform);
}
