Text layer

Charts, annotations and CLI motion for channels that render characters instead of pixels. Nine primitives, two encodings, one linter. Shipped in 1.2.0 as part of the versioned contract.

Consume it

Glyph ladders, column budgets and reserved marks are authored in tokens/text.json. npm run build emits the resolved spec and a self-contained Python renderer. Do not read tokens/ from a consumer.

npm run build
python3 dist/text.py --encoding unicode   # review board
python3 src/text/lint.py --file chart.txt --budget 44
npm run check:text                        # linter + golden board

Nine primitives

A closed set. Anything else is composition. Each function returns a string.

PrimitiveRole
sparkOne row, self-normalised curve. Sampling lives inside the primitive.
hbarFixed-scale bar. Bounded domains pin 0–100 so 9% cannot fill the row.
gridN×M matrix on a 4-step ladder. Blank cells are absence, not zero.
rangeA span with the current value marked inside it.
multiSmall multiples sharing one scale.
annotateCaret under a column, derived from the rendered string.
kvKey, dot leaders, value. The text form of .row-meta.
frameA Konstrukt module in text: heavy frame, meta right-aligned.
rulerMeasuring probe. Paste once; ragged means the channel is proportional.

The review sheet renders every primitive from the Python renderer, so the examples cannot drift from the grammar.

Encodings

Same ladder positions, two renderings. unicode is the default. ascii is for SMS, logs, and terminals that mangle block glyphs.

  unicode  ▁▃▅▇█▇▅▃ temp 53→74°
  ascii    .-+#@#+- temp 53→74°

  unicode  █████░░░  62%
  ascii    #####...  62%
