Integration

iOS & SwiftUI

Konstrukt ships a generated Swift package so native apps use the exact same token values as the web. Colors, spacing, radius, and font names are all typed.

1 · Add the package

The package is generated at apps/konstrukt/dist/swift/Konstrukt. Reference it by local path from a sibling app, or pin a tagged release once published.

// Package.swift
dependencies: [
    .package(path: "../hooman-loop/apps/konstrukt/dist/swift/Konstrukt"),
],
targets: [
    .target(name: "App", dependencies: ["Konstrukt"]),
]

In Xcode: File → Add Package Dependencies → Add Local… and select the Konstrukt folder.

2 · Resolve a theme

A KonstruktTheme is resolved from a mode. The palette parameter remains for source compatibility; atelier is the only palette, and the 1.x cases are deprecated aliases for it.

import Konstrukt

let theme = KonstruktTheme.theme(mode: .dark)
// theme.accent, theme.bg, theme.surface, theme.text, ...
TypeCases
KonstruktPalette.atelier (.hl · .courage · .minimal · .blueprint deprecated, resolve to .atelier)
KonstruktMode.light · .dark

3 · Use the environment

Inject a theme once near the root, then read it anywhere with @Environment.

import SwiftUI
import Konstrukt

struct RootView: View {
    @Environment(\.colorScheme) private var scheme
    var body: some View {
        ContentView()
            .konstruktTheme(mode: scheme == .dark ? .dark : .light)
    }
}

struct ContentView: View {
    @Environment(\.konstruktTheme) private var theme
    var body: some View {
        VStack(spacing: KonstruktSpacing.sp4) {
            Text("The Hooman Loop")
                .konstruktTextStyle(.heading)
                .foregroundStyle(theme.text)
            Text("Build once. Theme everywhere.")
                .foregroundStyle(theme.textMuted)
        }
        .padding(KonstruktSpacing.sp6)
        .background(theme.surface)
    }
}

4 · Typography roles

The same roles as the web, generated from tokens/global.json. Sizes are in points; tracking is stored in em and converted for you.

Text("Reference").konstruktTextStyle(.label)   // iOS 16+
Text("Konstrukt").konstruktTextStyle(.display)

let s = KonstruktTextStyle.meta
s.font           // Font.custom("Inter", size: 13).weight(.regular)
s.trackingPoints // tracking × size
s.lineSpacing    // (lineHeight − 1) × size

Roles: .display · .heading · .subheading · .label · .badge · .body · .meta · .mono

5 · Spacing, strokes, radius, fonts

KonstruktSpacing.sp1   // 4
KonstruktSpacing.sp4   // 16
KonstruktSpacing.sp16  // 64
KonstruktStroke.hairline // 1
KonstruktStroke.rule     // 2  (the ink rule)
KonstruktStroke.rail     // 4  (accent rail)
KonstruktRadius.base   // 0  (square corners)

KonstruktFont.display  // "Space Grotesk"
KonstruktFont.sans     // "Inter"
KonstruktFont.mono     // "SF Mono"

Register Space Grotesk and Inter in your app bundle (Info.plist UIAppFonts) to render the display and body families; SF Mono ships with the system.

Regenerating

The Swift sources are generated — never hand-edit them. Change a value in tokens/ and rebuild; the CSS, Swift, and JSON outputs update together.

npm run build
